# AETHERIA : Echoes of the Five Elements

Game action-RPG top-down berbasis web. Upload seluruh isi folder ini ke GitHub, aktifkan **Settings → Pages → Deploy from branch (root)**, lalu buka `https://<user>.github.io/<repo>/`.

Alur: Menu Utama → Pilih Karakter (8) → Peta → bertarung, naik level, pilih kekuatan acak (Pasif / Aktif / Kutukan).

Kontrol: WASD/analog gerak • Spasi/J atau tombol ⚔ serang (ada Auto) • 1 2 3 skill karakter • Q E R skill kekuatan Aktif • Shift dash • Esc jeda.

Semua aset di folder `assets/` adalah file asli yang dikirim (tidak dikompres / diubah). `assets/fx` = efek pixelfx yang dirender jadi sprite sheet.
