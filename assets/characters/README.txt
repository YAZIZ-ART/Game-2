KARAKTER SPRITESHEET PACK
Per karakter:
 character_skills/  -> animasi karakter per skill (192x192 per frame, baris: up,left,down,right)
 weapon_skills/     -> layer senjata sinkron dgn frame karakter (tumpuk di atas karakter; baris 'up' sebaiknya di bawah karakter)
 weapon/            -> sprite senjata 64x64 (pivot gagang di bawah-tengah)
 element/           -> spritesheet efek elemen (128x128 per frame, 12 kolom x 13 baris)
 *_data.json        -> CD, durasi, jumlah frame, frame_ms, urutan animasi
Sumber karakter: LPC (Universal LPC Spritesheet Generator) dari file KARAKTER.zip kamu.
